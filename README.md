# Entrega dos Códigos de Criptografia
```text
/RSA
  • RSA:
    - comando: python main_rsa.py "sua_mensagem"
        
  • Chat com RSA:
    - rodar chat_app.py em dois terminais com argumentos --name, --port (porta do remetente),
      -peer-port (porta do destinatário)
    - exemplo: python chat_app.py --name Bruna --port 5001 --peer-port 5002

/sha256
  • SHA256:
    - comando: python main_sha.py gerar "sua_mensagem"
  
  • Autenticador:
    - comandos:
      - python main_autenticador.py gerar <arquivo.txt>
      - python main_autenticador.py validar <arquivo.txt> <hash>
```
